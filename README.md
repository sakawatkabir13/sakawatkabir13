## Featured Projects

**[Real-time-cyber-attack-monitoring-and-threat-intelligence-platform](https://github.com/sakawatkabir13/Real-time-cyber-attack-monitoring-and-threat-intelligence-platform)**
Self-hosted real-time cyber attack monitoring and threat intelligence platform.
Detects SQLi, XSS, brute-force, and DDoS activity through a hybrid rule + ML
detection engine, ships via a lightweight log agent, and streams findings to a live
dashboard.

**[cinemaseat](https://github.com/sakawatkabir13/cinemaseat)**
Movie-ticket booking system built around one invariant: a seat is never sold twice.
Redis atomic holds + PostgreSQL unique constraints make double-booking structurally
impossible under concurrent load; load-tested at 100 simultaneous buyers contending
for one seat (1 success, 99 clean conflicts, 0 oversells). FastAPI async payment
flow with idempotent, HMAC-signed webhook handling; React/TypeScript frontend.
Built at the Zero to Production hackathon.

**[basilisk-shell](https://github.com/sakawatkabir13/basilisk-shell)**
AI-powered Linux terminal assistant that converts natural-language requests into
audited Bash commands, with layered safety checks, risk-gated execution, and
multilingual input handling.

**[full-custom-dns-spoofer-with-scapy](https://github.com/sakawatkabir13/full-custom-dns-spoofer-with-scapy)**
Educational Python toolkit for custom DNS spoofing with Scapy — MAC manipulation,
network scanning, ARP spoofing, packet sniffing, and targeted DNS response
interception in authorized lab environments.

**[hermes-cloud-agent-lab](https://github.com/sakawatkabir13/hermes-cloud-agent-lab)**
A reproducible personal AI agent stack running on a low-cost AWS EC2 VPS — Telegram
gateway, Hermes Agent, Ollama, and model routing across local Gemma GGUF and cloud
LLMs.

**[Self-Hosted-Cloud-Server](https://github.com/sakawatkabir13/Self-Hosted-Cloud-Server)**
Secure, containerized self-hosted cloud platform built with Nextcloud, MariaDB,
Redis, Pi-hole, Nginx Proxy Manager, and Twingate — private file storage, sync,
HTTPS access, and local DNS.

**[cuet-insights](https://github.com/sakawatkabir13/cuet-insights)** ·
**[cuet-jam](https://github.com/sakawatkabir13/cuet-jam)**
Two Spring Boot 3.2 + MySQL platforms built for the CUET community — complaints,
innovations, resource sharing, and posts (Insights); team-finding, lost & found, and
resource sharing (Jam).
